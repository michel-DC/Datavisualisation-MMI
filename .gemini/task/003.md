# Tâche — Section « Évolution des émissions de CO₂ en Guadeloupe »

## Contexte général

Tu interviens sur un projet de datavisualisation réalisé dans le cadre de la SAE 303 (BUT MMI).

Toutes les règles de développement, de structuration et d’écriture du code sont définies dans le fichier `AGENTS.md`.  
Ces règles doivent être respectées strictement, sans exception.

Stack utilisée :

- PHP
- Tailwind CSS
- Chart.js
- GSAP
- Lucide Icons

Le site est une **single page strictement non scrollable** (aucun scroll vertical ni horizontal).

---

## Objectif de la tâche

Créer la **section dédiée à l’évolution des émissions de gaz à effet de serre**, limitée **uniquement au CO₂**, en Guadeloupe.

Cette section doit permettre de visualiser :

- L’évolution annuelle des émissions de CO₂
- La répartition par **type de source d’émission**

Période couverte :

- **1990 à 2022**

Cette tâche concerne uniquement **cette section**.  
Aucune autre section du site ne doit être modifiée.

---

## Données (contrainte essentielle)

Pour cette étape du projet :

- **Aucune API ne doit être utilisée**
- **Aucune donnée réelle n’est requise**
- Les données doivent être :
  - **Fictives**
  - **Définies directement dans le code**
  - Cohérentes et plausibles pour des émissions de CO₂
- Les valeurs sont exprimées en :
  - **Milliers de tonnes de CO₂**

Toute source externe ou appel réseau est strictement interdit.

---

## Emplacement et structure

- La section doit être créée dans :
  - `/sections/emissions.php`
- Le graphique doit utiliser un script dédié situé dans :
  - `/script/`
- La section doit être compatible avec le système d’affichage / masquage existant
- La section doit occuper **100 % du viewport**, sans scroll

---

## Structure de la section

### 1. Introduction et titre

- Un **titre clair et explicite** doit être affiché
- Le titre doit être :
  - Lisible
  - Typographiquement fort
  - Positionné de manière cohérente avec les autres sections

Exemple de sens attendu (le wording exact est libre) :

- « Évolution des émissions de CO₂ en Guadeloupe »

---

### 2. Graphique principal — Bar chart

Le cœur de la section est un **bar chart Chart.js** représentant :

- L’évolution annuelle des émissions de CO₂
- Axe horizontal :
  - Années (1990 → 2022)
- Axe vertical :
  - Émissions de CO₂ en milliers de tonnes
- Les barres doivent être **segmentées par type d’émission**, par exemple :
  - Industrie de l’énergie
  - Transport
  - Agriculture
  - Résidentiel / tertiaire
  - Autres secteurs pertinents

Le graphique doit permettre de comprendre :

- La contribution de chaque secteur
- L’évolution globale et sectorielle dans le temps

---

## Contraintes graphiques

- Type de graphique : **bar chart**
- Barres empilées ou groupées selon le choix le plus lisible
- Lisibilité prioritaire sur l’esthétique
- Axes, légendes et labels clairs
- Palette de couleurs sobre et cohérente avec le reste du site
- Aucune couleur flashy
- Aucun gradient

Une animation d’apparition du graphique doit être présente et maîtrisée (GSAP).

---

## Contraintes UI / UX

- Style **strictement minimaliste**
- Interface de type dashboard
- Typographie large et hiérarchisée
- Espaces et alignements précis
- Aucun élément décoratif non justifié

L’objectif est de rendre immédiatement compréhensible la structure des émissions de CO₂.

---

## Contraintes techniques

- Utiliser Tailwind CSS pour le layout et le style
- Utiliser Chart.js uniquement pour le graphique
- Utiliser GSAP pour :
  - L’apparition de la section
  - L’animation du graphique
- Le code doit être :
  - Propre
  - Structuré
  - Lisible
  - **Sans commentaires**
- Une responsabilité par fichier
- Aucun code inutile ou expérimental
