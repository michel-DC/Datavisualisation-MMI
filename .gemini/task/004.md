# Tâche — Section « Évolution du cumul de rayonnement solaire en Guadeloupe »

## Contexte général

Tu interviens sur un projet de datavisualisation réalisé dans le cadre de la SAE 303 (BUT MMI).

Toutes les règles de développement, de structuration et d’écriture du code sont définies dans le fichier `AGENTS.md`.  
Ces règles doivent être respectées strictement, sans exception.

Stack utilisée :

- PHP
- Tailwind CSS
- Chart.js
- GSAP
- Lucide Icons

Le site est une **single page strictement non scrollable** (aucun scroll vertical ni horizontal).

---

## Objectif de la tâche

Créer la **section dédiée à l’analyse de l’évolution du cumul de rayonnement solaire en Guadeloupe**.

Cette section doit permettre de visualiser :

- L’évolution annuelle du **cumul de rayonnement solaire**
- Sur une période longue permettant d’observer une tendance climatique

Période couverte :

- **1951 à 2023**

Cette tâche concerne uniquement **cette section**.  
Aucune autre section du site ne doit être modifiée.

---

## Données (contrainte essentielle)

Pour cette étape du projet :

- **Aucune API ne doit être utilisée**
- **Aucune donnée réelle n’est requise**
- Les données doivent être :
  - **Fictives**
  - **Définies directement dans le code**
  - Plausibles et cohérentes avec des données de rayonnement solaire
- Les valeurs sont exprimées en :
  - **kJ/cm²**
- Les données doivent couvrir l’ensemble de la période **1951 → 2023**

Toute source externe ou appel réseau est strictement interdit.

---

## Emplacement et structure

- La section doit être créée dans :
  - `/sections/rayonnement.php`
- Le graphique doit utiliser un script dédié situé dans :
  - `/script/`
- La section doit être compatible avec le système d’affichage / masquage existant
- La section doit occuper **100 % du viewport**, sans scroll

---

## Structure de la section

### 1. Titre de la section

- Un **titre clair et explicite** doit être affiché
- Il doit être :
  - Lisible
  - Typographiquement fort
  - Positionné de manière cohérente avec les autres sections

Exemple de sens attendu (le wording exact est libre) :

- « Évolution du cumul de rayonnement solaire en Guadeloupe »

---

### 2. Graphique principal — Scatter chart

Le cœur de la section est un **scatter chart Chart.js** représentant :

- L’évolution annuelle du **cumul de rayonnement solaire**
- Axe horizontal :
  - Années (1951 → 2023)
- Axe vertical :
  - Rayonnement solaire cumulé en **kJ/cm²**
- Chaque point représente une année

Contraintes graphiques :

- Type de graphique : **scatter chart**
- Aucune ligne de tendance automatique non justifiée
- Densité de points maîtrisée
- Axes clairement nommés et lisibles
- Animation d’apparition fluide et maîtrisée (GSAP)

---

### 3. Légende du graphique

La légende du graphique est un élément central de cette section.

Contraintes obligatoires :

- La légende doit être **visuellement inspirée de l’exemple fourni**
- Elle représente une **échelle de valeurs de rayonnement**
- L’échelle doit être graduée (exemple : 1 000, 2 000, 3 000, 4 000, 5 000 kJ/cm²)
- La légende doit :
  - Être horizontale
  - Être lisible
  - Expliquer clairement l’unité et le sens des valeurs
- Le texte associé doit expliciter :
  - « Cumul de rayonnement global (kJ/cm²) »

Contraintes de style :

- Palette sobre
- Dégradé doux et non agressif
- Aucun effet décoratif superflu
- Cohérence visuelle avec le reste du site

---

## Contraintes UI / UX
